# La biblioteca de Celia

Creada a partir de la plantilla [martateikea/biblioteca](https://github.com/martateikea/biblioteca), con la estética «bebé».

- `config.js`: nombre, peque y URL del Sheet de Celia.
- `tema.css` y `textos.js`: aspecto y textos.
- `google-sheet/Codigo.gs`: el script que va pegado en el Apps Script de su Sheet.

Para actualizar el script: *Implementar → Gestionar implementaciones → lápiz → Versión: Nueva versión → Implementar*.
Nunca "Nueva implementación": cambiaría la URL y la web dejaría de funcionar.
